01
Document Ingestion and Vector Embedding
Processed all 80+ source documents — PDFs, spreadsheets, pricing tables, FAQ docs, floor plan specs — through a LangChain ingestion pipeline. Each document was chunked, embedded using OpenAI's text-embedding model, and stored in Pinecone vector database with rich metadata tags (property name, document type, last updated date). Total: 14,200 embedded chunks.
LangChainOpenAI EmbeddingsPineconePDF Parser
02
RAG Query Engine with GPT-4
Built a Retrieval-Augmented Generation pipeline: every client question is converted to an embedding, semantically searched against Pinecone to retrieve the 5 most relevant document chunks, then passed to GPT-4 with a custom system prompt to generate a precise, source-grounded answer — not a hallucination. Accuracy rate in testing: 97.4%.
GPT-4Pinecone Semantic SearchLangChain RAG
03
Multi-Channel Deployment
The AI assistant was deployed across three channels simultaneously: as a website chat widget, a WhatsApp integration, and an internal Slack bot for agents. All three use the same knowledge base — ensuring consistent answers everywhere, every time, to both clients and internal staff.
Web WidgetWhatsApp APISlack APIn8n
04
Automatic Knowledge Base Updates
Built a live update pipeline: when any source document is updated (e.g. new pricing sheet uploaded to Google Drive), an n8n workflow automatically re-ingests only the changed chunks, re-embeds them, and updates Pinecone. The AI always works from the latest data — no manual retraining or intervention required.
Google Drive Triggern8nPinecone Upsert
